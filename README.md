# Gemini.nvim
A dark Neovim colorscheme.

## Installation

### lazy.nvim

```lua
{
    "nchhillar2004/gemini.nvim",
    lazy = false,
    priority = 1000,
    config = function()
        vim.cmd.colorscheme("gemini")
    end,
}
```
