# Gemini.nvim
a minimal, dark theme for neovim inspired from the syntax highlight used by gemini.google.com in code blocks.

## Installation

### lazy.nvim

```lua
{
    "nchhillar2004/gemini.nvim",
    lazy = false,
    priority = 1000,
    config = function()
        vim.cmd.colorscheme("gemini")
    end,
}
```
